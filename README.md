# Mattermost Stickers

Плагин с PNG-стикерами для Mattermost Team Edition 11.7.3. Кнопка рядом с emoji открывает каталог с постепенной подгрузкой. Нажатие на стикер сразу отправляет его в чат или тред.

В браузере и Desktop стикеры отображаются без рамки. В мобильном приложении — как обычные вложения; кнопки выбора там нет.

## Установка

1. Соберите плагин по инструкции ниже.
2. Разрешите загрузку плагинов: `PluginSettings.EnableUploads: true`.
3. В **System Console → Plugins → Plugin Management** загрузите архив из `dist/` и включите **Stickers**.
4. Перезагрузите окно Mattermost.

Сборка поддерживает серверы Linux amd64 и arm64.

## Добавление стикеров

Системный администратор может загрузить PNG через **System Console → Plugins → Stickers → Каталог стикеров**.

Принимаются PNG до 512 КиБ и 2048×2048 px. Большие изображения уменьшаются до 192 px по длинной стороне с сохранением прозрачности. Каталог общий для всех пользователей.

Картинки и метаданные хранятся отдельно в KV Store Mattermost, каталог кэшируется в памяти. Версия 0.1.6 автоматически переносит старые записи, сохраняя исходные данные как резервные копии.

## Сборка

Нужны Node.js 22+ и Go 1.25+.

```sh
npm ci
npm run build
```

Установочный архив появится в `dist/`. Встроенные PNG берутся из `stickers/`.

Все проверки: `npm run check`. Для браузерных тестов нужен установленный Google Chrome.
